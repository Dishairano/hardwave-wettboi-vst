# WettBoi

WettBoi is a reverb and delay VST3/CLAP plugin with a built‑in sidechain ducker for harder‑styles production.

**Formats:** VST3, CLAP  
**Platforms:** Windows, macOS (Linux not supported)  
**Written in:** Rust (using `nih-plug`)

## Build

```sh
cargo xtask bundle hardwave-wettboi --release
```
